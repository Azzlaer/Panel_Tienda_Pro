CHILEMARKET TECH STABLE 1.1.0
================================

Esta versión corrige el problema de desorden visual de la versión 1.0.0.

CAUSA CORREGIDA
- La versión anterior usaba JavaScript para mover el hero, categorías y catálogo a un contenedor nuevo.
- Las secciones de promoción, rankings, noticias y pie de página quedaban fuera del flujo esperado.
- También duplicaba tarjetas de productos en una barra lateral.

CAMBIOS
- No mueve, clona ni elimina elementos del sitio.
- No agrega JavaScript.
- Mantiene el orden original generado por PHP.
- Solo aplica CSS bajo body.theme-chile-market-tech-stable.
- Es compatible con inicio, perfiles, artículos, formularios y páginas administrativas públicas.

INSTALACIÓN
1. Panel administrativo > Plantillas.
2. Subir este ZIP.
3. Inspeccionar e instalar.
4. Activar "ChileMarket Tech Stable".
5. Desactivar y eliminar la versión antigua cuando confirmes que todo funciona.
